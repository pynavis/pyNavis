# Screenshots the tools guide is waiting for

Save each as `docs/tools/_assets/shots/<name>.png` (PNG, about 1200 px wide, light Navisworks theme) and re-run `python tools/build_tools_site.py`. A page shows a labelled placeholder until its file exists.

- [ ] `console-window.png`: The console with a short script in the lower pane and its output above.
## Remember (Selection)

- [ ] `remember-toast.png`: The toast after Remember, counting what went into memory.
## Previous and Next (Selection)

- [ ] `next-walk.png`: Stepping through remembered items with Next: the view zooms to each one and the
toast counts where you are.
## More menu (Selection)

- [ ] `more-menu.png`: The More menu open: Show Contents, Save as Set, Purge.
## Clash Report (Clash)

- [ ] `clash-report-table.png`: The output window after Clash Report: one row per test, statuses across, totals

middle, the live preview of groups on the right.

flat list of hundreds.
## Clear Clash (Clash)

- [ ] `clear-clash-before-after.png`: A pipe through a beam before, and sitting on the beam after, with the dialog
