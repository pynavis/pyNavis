Playground

Browse pyNavis Playground, a catalog of experimental tools, and install only the ones you tick.

On the ribbonButton, pyNavis panel
NeedsAn internet connection to GitHub, or a catalog on this PC

What it does#

pyNavis Playground is a separate extension of experimental tools, each built from a request people made in public forums and product boards. This button opens a window over its online catalog: search it, read the request behind a tool, tick the tools you want and install just those. Nothing in the Playground is a finished pyNavis tool. Tools that prove themselves move into pyNavis proper.

How to use it#

  1. Click Playground. The window loads the catalog in the background.
  2. Search by title, summary, tab or panel, or pick a status to see only those tools. Ask under a tool opens the request that motivated it; hover it to read the quote.
  3. Tick the tools you want and click Install. pyNavis reloads and a toast names the tabs they landed on.
  4. To take tools out again, untick them and click Remove.

The status ladder#

Every tool carries an honest status, and it only goes up on evidence:

  • Untested: never run inside Navisworks. It passed automated checks only.
  • Launched: ran inside Navisworks with no error logged, but no person checked the result.
  • Verified: a person confirmed it does what it says on a real model.
  • Known issue: ran and misbehaved. The note under it says how. You can still install it.

Where things go#

  • Installed tools land in %APPDATA%\pyNavis\extensions\Playground.extension, a folder pyNavis always scans. Open folder shows it.
  • The download, the last catalog that loaded and the list of what you installed live in %APPDATA%\pyNavis\playground. The download is checked against the SHA-256 in the catalog before anything is copied.
  • A tool in a stack brings the rest of its stack with it, because pyNavis skips a stack that has only one button. The row says so before you install.
  • Installing more tools later leaves the ones you already have, and any changes you made to them, alone. Removing a tool deletes its folder, changes included.

Shift+Click#

Sets where the catalog comes from. Leave it empty for the catalog on GitHub, or give a web address or the path of a catalog.json on this PC or a share, for working offline or trying a catalog before it is published. The setting is playground.catalog in config.json. The same window opens the install folder.

Limitations#

  • The tools are experimental. Try one on a copy of a model first.
  • When GitHub cannot be reached, a toast says so and the window shows the last catalog this PC loaded, if there is one.
  • A catalog that asks for a newer pyNavis can be browsed but not installed from.
