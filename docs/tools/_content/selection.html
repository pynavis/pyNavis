Navisworks has no undo for selections. Click the wrong thing and a selection you spent ten minutes building is gone. The Selection panel is one register of items per document, the way a calculator has a memory: put a selection in it, keep working, take it back out. It lives on disk under %APPDATA%\pyNavis\memory\, keyed to the document, so it survives closing the model and closing Navisworks, and nothing is written into the model file.

The usual run of it: Remember what you have selected, Add, Subtract and Intersect as you find more, Recall to select the whole thing again, Previous and Next to walk the items one at a time, and Save as Set when the result is worth keeping in the document. None of these buttons greys out; an empty memory or an empty selection is reported in a toast.

What it does

Replaces the memory with the current selection and toasts how many items went in. This is the starting point for everything else on the panel.

How to use it

  1. Select anything: a click in the view, a Find Items result, a selection set.
  2. Press Ctrl+Shift+M or click Remember.
  3. Carry on. Hide things, section, click elsewhere. The memory keeps what you had.

Limitations

  • One memory per document. Remember replaces it; use Add to grow it instead.
  • Items are stored by their path in the model tree. If the model is republished with a different structure, some items may not resolve on Recall, and the toast will say how many.

Other uses

  • Before a risky operation, Remember the selection so a mis-click costs nothing.
  • Remember at the end of the day; the memory is still there tomorrow.

What it does

Resolves every stored item back to the model and selects it. Items that are no longer there, because the model was reloaded or the item deleted, are counted in the toast and skipped rather than failing the whole recall.

How to use it

  1. Press Ctrl+Shift+R or click Recall.
  2. The selection is back. Zoom to it with Navisworks' own Zoom Selected if you moved.

Limitations

  • Recall replaces the current selection. To combine, Recall first and then add to the selection by hand, or use Add and Intersect in the other direction.
  • An empty memory toasts "Memory is empty" and leaves the selection alone.

Other uses

  • Hand a colleague a selection: Save as Set puts it in the document; Recall is the private version that stays yours.

What it does

Unions the current selection into the memory. Use it to build up a set over several passes through a model: find some pipes on level 2, Add, find the rest on level 3, Add.

How to use it

  1. Remember a first selection.
  2. Select more. Click Add. The toast gives the new total.
  3. Repeat, then Recall to see the whole set.

Limitations

  • An item already in memory is not counted twice.

What it does

Takes the current selection out of the memory. The way to carve the unwanted part out of a stored set: Recall, click the items that should not be there, Subtract.

How to use it

  1. Recall the memory.
  2. Select only the items to drop. Click Subtract.
  3. Recall again to check.

Other uses

  • Everything except: Remember a whole system, select the part that is finished, Subtract, and the memory is the outstanding work.

What it does

Two searches reduced to what they agree on: one stored in memory, one live in the selection. What survives is the overlap.

How to use it

  1. Run a search, say everything on Level 3, and Remember it.
  2. Run another, say every item with Fire Rating set, and select it.
  3. Click Intersect. The memory is now the fire-rated items on Level 3. Recall to select them.

Limitations

  • Intersect with an empty selection empties the memory, because nothing is in both. The toast says so.

Other uses

  • Any two Find Items searches that Navisworks cannot combine in one query.

What it does

Selects a single item from the memory and zooms to it, then the one after it, then the next. This is how you walk a list of items you found earlier without losing your place: review each clash element, each unresolved comment, each item on a snag list.

How to use it

  1. Remember the list of items to review.
  2. Press Ctrl+Shift+Right. The first item is selected and the camera zooms to it.
  3. Keep pressing. Both directions wrap around, so Next at the end returns to the start.

Limitations

  • The camera move cannot be undone. Save a viewpoint first if you want to come back.
  • The order is the order the items were stored in, which is the order Navisworks listed them at Remember time.

Other uses

  • A quick model walkthrough for a meeting: Remember the ten things to show, then step through them with one hand while talking.

What it does

Empties the memory for this document and reports how many items were dropped. Other documents keep theirs.

Good to know

You rarely need this: Remember replaces the memory anyway. It is there for the moment you want to be certain nothing is stored, and for tidying up after a job. To delete the stored files for every document at once, use Purge in the More menu.

What it does

The pulldown at the end of the panel holds the three things you do to the memory rather than with it.

Show Contents

Lists the memory in the output window, one row per item with the model it came from and a link that selects it, under a line naming the document it was remembered from and when. Long memories are cut off at 500 rows. An empty memory prints a line telling you to select something and press Remember.

Save as Set

Promotes the memory to a native Navisworks selection set. It asks for a name, offering "Memory" plus the date and time, and creates the set. Unlike the memory, a selection set is stored inside the document, so this marks the document modified and the set travels with the file. This is how a private memory becomes something the team can see.

Purge

Deletes the stored memory files for every document, not just this one. It counts the files first and asks for confirmation naming that number, and says so quietly when there is nothing to delete.

Limitations

  • Save as Set makes a static set of the items as they are now, not a search, so it does not follow the model when new items match.
